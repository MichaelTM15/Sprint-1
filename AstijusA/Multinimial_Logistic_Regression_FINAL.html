1. Introduction and data cleaning

Multinoimial regression contributes three things other methods cannot:

  1. Directly interpretable coefficients. Each coefficient is a log-odds ratio for one outcome relative to a baseline.

  2. It directly estimates probabilities for Home, Draw and Away.

  3. It provides a benchmark for assessing whether more complex methods improve performance e.g. if random forests or SVMs perform similarly, their added complexity may offer little benefit.

1.3 Clean the rows and create simple features

We remove rows with missing outcomes or missing values in the 12 match statistics. This keeps model comparisons on the same matches. It may introduce bias if missingness is related to the match or league.

We also create differences (home minus away) and totals (home plus away). The difference describes which side has the advantage and the total describes the overall output during the match.

prepare_matches <- function(data, predictors) {
  
  # Keep the original row number so predictions can be matched across models.
  data$source_row <- seq_len(nrow(data))

  keep <- complete.cases(data[, c("FTR", predictors), drop = FALSE])
  data <- data[keep, , drop = FALSE]

  # Differences
  data$d_sot <- data$HST - data$AST
  data$d_shots <- data$HS - data$AS
  data$d_corners <- data$HC - data$AC

  # Totals
  data$t_sot <- data$HST + data$AST
  data$t_shots <- data$HS + data$AS
  data$t_corners <- data$HC + data$AC

  data
}

3. Model selection

3.1 What multinomial logistic regression estimates

The response has three unordered classes: draw, away win and home win. Multinomial logistic regression estimates a probability for each class, with the probabilities adding to one:

\[ P(Y_i = k \mid \mathbf{x}_i) = \frac{\exp(\alpha_k + \mathbf{x}_i^\top\boldsymbol{\beta}_k)} {\sum_{j \in \{D,A,H\}} \exp(\alpha_j + \mathbf{x}_i^\top\boldsymbol{\beta}_j)}. \]

This model estimates probabilities for Home, Draw and Away. With Draw as the reference, coefficients describe changes in home versus draw and away versus draw log-odds.

3.2 Models to compare

Each model addresses a specific question, whether shots on target dominate performance, whether other statistics add information, and whether an interaction improves fit. Backward selection tests whether a smaller model is sufficient.

  1. Null baseline: intercept only
  2. Full statistics: includes all 12 statistics
  3. Shots and corners: a smaller model focused on attacking output
  4. Differences and totals: differenced and total statistics between home and away
  5. Difference-total interaction: interaction term
  6. Without shots on target: checks whether the result depends heavily on SoT.
  7. Backward AIC: starts with the full model and removes terms when it improves AIC.

Why I’ve chosen to investigate the interaction term ? A difference of two shots on target could mean 4 versus 2 or 12 versus 10. The difference is the same, but the overall match output is not. The interaction tests whether the relationship between the difference and outcome changes with the total and if it can accurately classify our matches.

5.2 Define performance metrics

score_predictions <- function(model, test_data) {
  # Predict probabilities
  probabilities <- predict(model, newdata = test_data, type = "probs")

  # Predict the outcome with the highest probability
  predicted <- colnames(probabilities)[max.col(probabilities)]
  
  # Percentage correct
  correct_percent <- mean(predicted == test_data$FTR) * 100

  # Calculate ROC curves and AUC
  roc_results <- list()
  auc_results <- numeric()

  for (outcome in colnames(probabilities)) {

    roc_results[[outcome]] <- roc(
      test_data$FTR == outcome,
      probabilities[, outcome],
      quiet = TRUE
    )

    auc_results[outcome] <- as.numeric(
      auc(roc_results[[outcome]])
    )
  }

  # Return results
  list(
    CorrectPercent = correct_percent,
    AUC = auc_results,
    ROC = roc_results
  )
}

The two odds enhanced models have almost identical ROC performance, with AUCs around \(0.8\) for home wins, \(0.815\) for away wins and \(0.63\) for draws. Both outperform the full statistics model across all three outcomes.

Draws remain the hardest outcome to classify, even after introducing odds. One possible reason is that two teams can record similar shots and shots on target, yet one still wins narrowly. This overlap makes it harder for the model to identify a clear pattern separating draws from wins.

7. Conclusion & Limitations

7.1 Conclusion

The full statistics plus odds model achieved the highest accuracy of \(60.13\%\), compared with \(45.49\%\) for the majority class baseline discussed in the initial EDA section.

Feature sensitivity analysis helped identify where the information came from. Using backwards AIC for the full model we identified, away yellow cards as the least important predictor. Removing shots on target reduced accuracy from \(57.12\%\) to \(51.40\%\), while the shots on target only model achieved \(55.98\%\). Therefore SoT account for much but not all of the information/model’s performance. Adding bookmaker odds provided further gains to accuracy.

Our most important finding was a strong weakness of the model in predicting draws. The difference interaction plus odds model only correctly identified a shocking \(6.3\%\) of actual draws, compared with a respectable \(82.6\%\) of home wins and a moderate \(69.4\%\) of away wins.

The confusion matrix changed our interpretation of our overall performance. The multinomial model was reasonably effective at identifying wins, but was not a balanced three outcome classifier, especially for draws.

7.2 Limits of the data set

The available data limits how accurately we can distinguish draws from narrow victories. Similar numbers of shots, shots on target and corners can classify either result, leaving no clear statistical separation. Adding more parameters cannot fully compensate for missing information.
