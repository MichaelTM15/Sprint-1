0. Introduction

In this file we will import the dataset, perform some Exploratory Data Analysis on it and export half-cleaned full, training and test datasets for later use to fit classification models.

We are pulling all our data from https://football-data.co.uk/data.php, a site containing results, match statistics and betting odds since the 2003/2004 season, and basic stats since the second Premier League season in 1993/94. The website states that the data is free to use for private individuals, but not for commercial use (including products trained on the data). The website also contains data for other countries’ leagues, a collection of betting articles and various other resources.

We won’t go through the names and meanings of all of the recorded variables, but they can be viewed here https://football-data.co.uk/notes.txt

1. Data Import

First we download all of the files that we will be using. We chose to take all of the data for each of the four English leagues from the 2003/2004 season onwards. This was motivated by this being the first season where the website had recorded any bookmakers’ odds. With one of our ideas to use the betting odds to improve the classifiers’ performances, this felt like a natural cutoff point. While there are an increasing number of variables that are recorded season upon season, the only requirement to be downloaded was for any betting odds to be one of them.

files<-list.files(
  file.path("..", "data"),
  pattern = "\\.csv$",
  full.names = TRUE
)

data_list<-list()

for(i in seq_along(files)){
  df<-read.csv(files[i])
  
# This deals with a bug in the data. Some rows of certain seasons had empty strings,
# which caused additional matches to be added with no information.
  df<-df[!is.na(df$Date) & df$Date!="", ]
  
  file_name<-basename(files[i])
  
# This creates a Season variable, by recording the years from the file name
  df$Season<-substr(
    file_name,
    nchar(file_name)-7,
    nchar(file_name)-4
  )
  
# Likewise this creates a League variable
  if(grepl("Premier_League", file_name)){
    df$League<-"Premier League"
  }
  else if(grepl("Championship", file_name)){
    df$League<-"Championship"
  }
  else if(grepl("League_1", file_name)){
    df$League<-"League 1"
  }
  else if(grepl("League_2", file_name)){
    df$League<-"League 2"
  }
  
  data_list[[i]]<-df
}

# This ensures that the dimensions of all of the data are the same by creating N/A columns for variables
# that aren't recorded in certain seasons 
all_columns<-unique(unlist(lapply(data_list, names)))
data_list<-lapply(data_list, function(df){
  missing_columns<-setdiff(all_columns, names(df))
  df[missing_columns]<-NA
  df<-df[all_columns]
  return(df)
})

# Creating the data frame
data<-do.call(rbind, data_list)

This shows that the leagues have largely similar distributions of outcomes between these seasons, which suggests it may be possible to use the data for predictions across division.

The main noticeable difference between the Premier League and the lower leagues is that there is a lower proportion of draws in the top league - and this deficit seems to be almost entirely made up in a higher proportion of Home wins. This could suggest that having the home advantage may have a stronger effect that tips a draw into a win for the home team, more times on average in the top division.

But this doesn’t tell the full tale - as it’s an aggregated proportion over 23 years. It could be that in the seasons themselves, vastly different things were happening in each league. Therefore we will plot line graphs for these outcome proportions for each league over time:

seasons<-sort(unique(data$Season))
season_years<-2003:(2003 + length(seasons) - 1)
leagues<-unique(data$League)

par(mfrow=c(2,2))

for(league in leagues){
  league_data<-data[data$League==league, ]
  proportions<-sapply(seasons, function(s){
    matches<-league_data[league_data$Season==s, "FTR"]
    prop.table(table(factor(matches, levels = c("H", "D", "A"))))
  })
  matplot(season_years, t(proportions),
        type="l", lty = 1, lwd=2,
        col=c("blue", "green", "red"),
        ylim=c(0,1),

        xlab="Season", ylab = "Proportion of Matches")
  legend("right", legend = c("Home Win", "Draw", "Away Win"),
       col = c("blue", "green", "red"),
       lty=1, lwd=2, cex=0.7)
}

From these we can see that even with a few slight seasonal fluctuations, the pattern across all leagues was broadly similar. The Home win took the largest chunk of the overall proportion across pretty much all seasons for each league, with the Draw and Away win amounts being quite similar in each.

Another thing to look into is even if the outcome is the same, how did the scores compare? For example a full time score 3-3 is much different to Nil-Nil - it tells us that the match was much more open and attacking from both sides, which let goals flow in on either end. With both higher Home and Away goals than the others, the Premier League is the league with the biggest scorelines. However, the Home advantage still seems to be the biggest difference maker, as it actually still has the largest average difference in goals between the teams. In fact, one can see that the average H-A goal difference increases going up each rung of the league ladder - with the largest jump from the Championship to the PL.

This doesn’t prove that the PL is necessarily the ‘most attacking’. As each club will play each other twice per season; once Home and once Away, the higher Away goals could potentially be inflated by the stronger teams in the case that the Premier League has the largest ‘skill’ difference between its top dogs and the rest of the pack.

The more interesting variables included in the dataset include all of the many betting odds. Both Opening and Closing Odds are recorded for each bookmaker in each market. There are 3 main markets: 1x2 (the standard, where you just predict the result); Over/Under 2.5 total goals (as it sounds); and Asian Handicap (a bit more complicated, it gives the ‘better’ team a handicap to overcome).

We may want to see how the Opening and Closing Odds relate to each other across the dataset. There are a lot of betting sites, so for now we will only show the correlation plots for the Bet365 Opening and Closing outcomes for each of the three outcomes:

3. Creating the Train and Test data

Now we will begin to remove some variables that we don’t want the classification models to use. The obvious ones include Full Time Home/Away goals, as in combination these just give the Full Time Result. Furthermore we don’t want any number of goals at Halftime to be shown either, as this gives too much information (as does the Halftime Result, clearly).

We decided to not include the Time of kickoff and name of the Referee as we don’t want to introduce unnecessary variance to any model which trains on these, in case there happens to be some association to match results.

Date and Season, and Division and League respectively overlap with each other. We want to consider the lower leagues as a full, combined dataset, which is why we remove their tags. Taking into account changes in the football landscape over time is a complex task, and when creating a model we don’t want to have to make any assumptions about dependence between the results across multiple seasons. So we will remove when the games were played and will treat each match as separate observation, without accounting for any such possible dependence.

Some less obvious variables we remove are the Home and Away Team names. This is to prevent the models from trying to learn which teams are stronger, which can change between seasons (which we’ve already removed).

‘X’ was a dummy variable that was N/A in all rows. Grouping it and all the other variables just mentioned:

remove_vars_0<-c("Div", "Date", "HomeTeam", "AwayTeam", "Referee", "Time", "X", "Season", "League", "FTHG", 
                 "FTAG", "HTAG", "HTHG", "HTR")

Now there are a lot of Betting Odds that we will remove. All summary statistics, including maximum and average odds, and the number of bookmakers to calculate the average odds, are removed as they are trivial to calculate.

Due to the results of the earlier investigation, we had the decision to remove either opening or closing odds from the bookmakers as they were so heavily correlated with each other across the board. Ultimately we chose to keep the opening odds, as they are more of a reflection of the betting site’s initial opinion before being influenced by any kind of market reactions. One could use the closing odds instead, or both, but for our experiment the opening odds fit the purpose we wanted them for better.

Putting together all of the odds to remove:
